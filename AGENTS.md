# telegram-bot — инструкции для AI-агентов

Telegram-бот Netlazy. Токен, Mongo и мастер-ключ читаются из окружения (`telegram_bot_token`, `mongodb_uri`, `bot_master_key`). Webhook берётся из `webhook_base_url` или `RENDER_EXTERNAL_URL`. Сервер — aiohttp, локальный порт по умолчанию 8080.

Учётная запись Netlazy — пара ключей, которую создаёт браузер, а не пароль. Бот не заводит парольный вход. `user_id` там — хеш открытых ключей, это не публичный id профиля.

## Опыт

Если по ходу задачи стало ясно то, что в следующий раз сэкономит неверный ход, допиши это в этот `AGENTS.md`. Ход работы и разовую ошибку не копируй. Неверную старую строку поправь, а не оставляй вторую рядом.

## Правила

- `.env`, токен бота, строку Mongo и мастер-ключ не печатать и не коммитить.
- Коммит и пуш — только когда владелец прямо просит. Push в `main` зеркалится на GitLab.
- Не подменяй API Netlazy своим хранилищем профилей. Контракт смотри в cutaway `netlazy/` и в `api_client.py`.
